# 滴灌水力计算交互程序

一个使用 Streamlit 编写的滴灌毛管水力分析网页工具，支持等间距与变间距布局、分区规格替换、均匀度分析、批量扫描和 Excel 导出。

## 主要功能

- 普通滴头和压力补偿滴头的流量指数设置。
- 等间距与循环变间距两种毛管布局。
- 指定长度、目标末端水头和 Cu 达标长度分析。
- 按水头积分分区，并从可用规格中迭代替换滴头。
- 水头、流量、分区和均匀度图表。
- 单次计算与批量参数扫描。
- 初始状态、替换结果和迭代记录的 Excel 导出。

## 运行环境

Windows 10/11，已安装 Python。建议使用 Python 3.10 或更高版本。

## 安装与启动

在本项目文件夹中打开终端，执行：

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

浏览器通常会自动打开 <http://localhost:8501>。如果没有自动打开，请手动访问该地址。

## 使用方法

1. 在左侧设置滴头、管道和分区参数。
2. 选择等间距或变间距布局。
3. 选择只看初始状态，或进行初始与替换对比。
4. 点击“运行计算”。
5. 查看图表与指标，必要时下载 Excel 结果。

## 计算说明

程序采用递减流量法迭代求解毛管水力状态。滴头出流采用 `q = k × h^n`，并根据流速、雷诺数、沿程损失和局部损失计算水头。均匀度采用 Christiansen Cu 指标。

当前版本的摩擦系数模型采用层流泊肃叶公式和湍流 Blasius 公式，层流与湍流切换处可能存在不连续。结果用于方案分析前，应结合实际管径、滴头样本和设计规范进一步校核。

## 本次修复记录

- 目标末端水头搜索覆盖完整滴头范围，避免漏掉短管段最优解。
- 初始和替换结果分别使用各自的流量指数生成 Excel。
- 记录每轮真实 Cu，不再用插值模拟收敛曲线。
- 检查非正间距、无效分区、空布局和非法数值输入。
- 记录求解收敛状态和水头下限，提供风险提示。
- 批量计算遵循布局启用状态，详情导出使用对应结果的配置快照。
- 单次下载复用预生成的 Excel，避免界面刷新时重复计算。
